# SmartSecure Insurance Management System

A full-stack microservices-based insurance management platform built with Spring Boot and Angular.

## Features
- User registration & authentication (JWT)
- Browse & purchase insurance policies
- File and track claims
- Admin dashboard
- Email OTP verification

## Tech Stack
- **Frontend**: Angular 17
- **Backend**: Spring Boot microservices (API Gateway, Auth, Policy, Claims, Admin)
- **Database**: PostgreSQL
- **Cache**: Redis
- **Message Broker**: RabbitMQ
- **Service Discovery**: Eureka
- **Tracing**: Zipkin
